# 材质重建、烘焙与预览

## 先确定 Skyrim 端的材质语义

读取每个 NIF shape 的 `BSLightingShaderProperty`、贴图槽、Shader Flags 和 alpha。记录颜色、法线、反射遮罩、环境贴图、Glossiness、Specular、透明或发光用法。DDS 命名有参考价值，通道含义以实际数据和 NIF 设置为准。金属区、染色布、皮革、油漆及反射遮罩分别标记。源环境反射通常不能从底色贴图推断。

## 选择 PBZ 父材质，再准备贴图

1. 用 FModel 找游戏中渲染行为接近的衣料、皮革、金属、皮肤和头发。查看父级链、材质层、采样类型、透明模式和参数 `Name`、`Association`、`Index`。在 UE 做私有 Material Instance，引用游戏实际提供的兼容父材质及现有 shader 排列。自制材质、新静态开关和自编 shader 要单独做兼容性验证。
2. 原始 UV 未改时尽量直接转换或重打包源贴图。UV 改动或跨网格皮肤过渡时，在 Blender 以接收网格 UV 新建目标图像。使用 Cycles 的 Selected to Active，按解剖区域或部件分开投射，用 cage 或射线距离避免采到旁边的衣层。将颜色、线性遮罩和切线法线分别输出。给 UV 岛留足边缘扩展，检查左右与接缝，再导入 UE。
3. 用目标父材质的实际格式写入贴图。先制作少量材质样片，导入 UE 后逐一核对：

   | 贴图 | 设置与检查 |
   |---|---|
   | Base Color | 通常启用 sRGB。校准布、皮革与金属的底色，保留纹理明暗。 |
   | Normal | 使用 Normalmap 压缩和线性采样。在斜光下用已知凸凹判断绿通道是否需翻转。 |
   | AO、粗糙度、金属度等打包图 | 关闭 sRGB，按父材质的读取约定打包。例如父材质确认 R=AO、G=Roughness、B=Metallic 时使用这个顺序。 |
   | 透明、发光或反射遮罩 | 按实际父材质的槽、alpha 和混合模式选择。虚拟纹理开关要与采样器一致。 |

4. 检查标量的实际调节范围及继承值。粗糙度和金属度按区域制作，尤其要保留金属花纹与底布的不同反射响应。从 EnvMask 近似金属属性时先看它实际覆盖什么，再用局部遮罩修正。复用皮肤实例时对应保留有效的层标量和颜色参数，检查肤色、粗糙度和背光响应。

FModel 导出的属性与贴图用于重建制作数据。编辑器缺少可用的原父材质时，可建立同包路径、同对象名及兼容对象类型的制作占位。让私有 Material Instance 指向占位，按实际游戏材质键写入动态参数。层参数在占位材质面板不可见时，可使用 UE 编辑器 Python 的参数值数组或小型编辑器 helper 显式写入 `MaterialParameterInfo`。保存后回读参数名、Association 和 Index。最终白名单排除占位，并在含游戏本体的挂载环境确认成品实例由正确的游戏父材质解析。

## 烘焙完成后的预览

在最终材质定版和正式封包之前展示可检查的画面。优先用实际 PBZ 材质或临时测试包的游戏预览，按实测分工执行。只有 UE 占位材质或 Blender 预览时，注明所用着色器和光照。至少给一张中性光全身图，以及一张能看出金属反射、织物或压花的斜光近景。多配色时在同机位和光照下对照原色与所有候选。

告知用户「如果希望 PBZ 尽量还原这套服装在 Skyrim 里的渲染观感，最好提供该 Mod 在 Skyrim 中的截图。中性光下的全身图和侧光近景通常就够开始对照。」若目标是开发者自己的 ENB 或 Community Shaders 环境，优先使用该环境截图。没有截图时可用原作者实机图、源 NIF 与 DDS 参数，以及第一轮 PBZ 实机图建立基准。记录用户认可的参考、光照和仍需校准的部件。用户要求先看再决定时，在该节点停下等待反馈。

对照时优先统一视角、曝光及光线方向，分开比较配色、金属高光、粗糙度、纹理细节和透光。Skyrim 与 PBZ 的环境反射、色调映射和光照模型各有差异，以用户确认的观感为定版依据。若修改了材质父级、贴图通道或采样类型，重新回读 Cook 后实例和贴图。
