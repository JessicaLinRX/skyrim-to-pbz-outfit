# 头部策略与颈部衔接

## 先确定游戏里要显示的头部

| 输入 | 实现 |
|---|---|
| 开发者提供头模 | 使用该模型，核对材质、LOD、头颈骨、面部动画方案、眼部、眉睫和头发。只移除确认不需要的源服装发型。头模自带或与其配套的头发应随头模保留，单独定义头盔开关。 |
| 源服装与配套身体明确为女性，且没有可用的女性头模 | 告知开发者需要提供或确认一个匹配的女性头模。确认后再完成头颈接缝、肤色匹配与外观注册。 |
| 开发者明确指定沿用 PBZ 原版男主外观 | 按当前框架选择对应的原生发型和过场变体，并验证头颈与目标身体匹配。 |
| 源体型不明确或有多种变体 | 查看 NIF 中的身体网格、BodySlide 预设和资产说明，确认要移植的变体及头部方案。 |
| 开发者需要女性头模但没有选型 | 可以推荐 SoulVerR（Soul Ver.R）作为候选。采用前确认开发者选择，核对适配、来源及跨 Mod 使用权限。携带第三方头模时获得相应许可，保留外部引用时列明依赖。 |

框架开发包的 `WriteMod` 可能要求 `HeadMesh`、`GameHeadMesh` 或 `GameHairstyle` 至少有一项。已知版本以 `GameHairstyle=DefaultHairStyle` 生成到游戏原生普通和 `_Seq` 行的引用。先确认目标版本中这些行的名称和男主资产指向。自定义头模时检查是否同时填了优先级更高的 `GameHairstyle`，这会使自定义 `HeadMesh` 不生效。[外观与换装选项](outfit-framework.md)

## 制作接缝

1. 把实际渲染的 PBZ 头部和候选身体放在同一参考姿势。选用游戏原生头部时，以其颈口作为测量参考，只改私有身体一侧。查所用 LOD 的可见皮肤边界，排除导出后仍存在的隐藏面。高领始终覆盖时可以把接缝放到领内，任何能去掉领饰的配置都需验证裸露颈部。
2. 提取头部颈口环，从身体上选取可连续过渡的一圈。识别 UV 或分裂法线产生的重合顶点。环点数不一致时可以按周向顺序加入中间截面并桥接。边界对齐位置、PBZ 公共骨权重与法线，身体侧逐圈渐变，保留肩胸与原身 UV。
3. 从正、侧和四分之三角度检查，下巴到领口的距离与颈部宽深分别调整。保护锁骨、肩线和下颌。移动自定义头部时同步检查眼、眉睫、发型挂点及头饰。用最终头部验证头盔缩放、位置和隐藏后的发型。
4. 存在皮肤色差时，在接颈用的独立皮肤槽烘焙过渡，按父材质核对颜色、法线、粗糙度及皮下响应。先识别硬线来自几何、骨权重、法线、UV 或材质，再改对应层。[材质制作](materials.md)

用转头、低头、跑停及下蹲动作复核露颈状态与头盔。编辑器和 Cook 后都对照实际头身网格、法线和变形。实机切换头部相关部件，检查普通游玩、过场和返场。
