# 游戏验收、运行时扩展与排查

## 验收矩阵

| 场景 | 观察项 |
|---|---|
| 基础环境与启动 | 先验证目标游戏与前置。启用候选后进主菜单、读档、进入游玩和切图。 |
| 外观与普通动作 | 独立外观、原外观完整。确认头、发、眉睫、服装、配色、颈口和鞋底。在持械、跑停、转身、蹲起和攻击中查看权重与布料。 |
| 换装选项 | 换装预览与游玩分别检查每组显隐及配色。覆盖默认、快速连切、换出换回、重载存档、切图、适用过场和返场。 |
| 可选兼容性 | 只启用必需依赖验证默认外观，再分别开启私有脚本或 UUEPBS。核对场景与动画实例重建后的重绑。 |

以已安装文件和候选 ZIP 的哈希对应结果。保存日志、转储的触发时间及最后一次成功操作。编辑器、Cook 回读、脚本回放和游戏都单独记录。离线验证后可交给约定的实测者，并标明待测项。

## 按现象找故障层

| 现象 | 先核对 |
|---|---|
| 启动或加载崩溃，出现 Texture2D Serial size mismatch | 检查带版本与 Tagged 属性，重做纹理解码，并验证实际安装候选。 |
| 仅游戏渲染时崩溃 | 对照转储、shader 排列及材质父级。优先用游戏已支持的动态材质实例缩小范围。 |
| 部件纯色、纹理被拉糊 | 检查导出前后的 UV0、材质槽、贴图采样及压缩。 |
| 选项有 UI 但画面不变 | 核对实际目标网格、LOD section、材质参数或选项值到行为的绑定。 |
| 隐藏头盔后光头 | 分别核对头模、配套头发与头盔开关，检查普通和过场发型条目。 |
| 参考姿势正常，动作中破皮或开缝 | 定位问题帧，回读姿势、公共骨参考变换、权重、组件姿势来源和物理。 |
| 预览或过场与游玩状态不同 | 确认是否使用另一个 Actor、World、网格、动画实例或保存键，核对框架实际支持范围。 |

启动问题可按「本体 + 前置、再加候选网格和表、再加私有脚本」逐步定位。逐层替换或禁用时保留原可用包及已知问题包的哈希。崩溃报告区分确认的故障调用、推测原因和修复后验证。

## UE4SS 对象生命周期

- 在游戏线程逐级确认 Actor、Level、World 和目标组件。检查 `GetLevel()` 返回值有效再调用 `GetOuter()`。排除模板、类默认对象和其他 World 的对象。关卡未就绪时延后扫描。切图、换装预览重建或过场接管后重新定位组件和动画实例。Lua `pcall` 无法接住原生访问违规。
- 跨帧保存资源路径和选项值。使用跨帧引用需有引擎侧生命周期保障。Lua 包装和 `IsValid()` 各自不足以保证旧材质引用继续存活。应用换色时按路径解析并加载，再确认整组材质和实际渲染网格有效，于游戏线程写入。资源不齐时保留当前配色。快速切换可合并中间事件，只应用最新选择；测试其最终值、换装和过场重绑。
- 对最终 ZIP 的实际脚本做回放。覆盖无有效 Level 或 World、冷加载、回切、模拟回收后包装失效、快速连切、部分资源未齐及组件重建。再按约定做游戏复测。

## 靴底定位

先区分 Blender/FBX/UE 往返的高度差、原生日常动画下的姿势差和游戏碰撞。用 Cook 后的靴底顶点分别测参考姿势和失败动作的左右鞋尖、前掌与后跟，定位真正的主姿势源、可见服装组件及地面高度。

确实属于小幅动态接地误差且项目有私有 Copy Pose AnimBP 时，可在输出前为左右脚骨添加局部上移，按鞋底净空独立补偿。净空用未补偿的源姿势和实际组件到世界变换估算，再与可行走地面或 trace 结果比较。已请求的位移和实际渲染位移分别记录，避免补偿追涨。悬空或无有效地面时归零，保留角色的原生移动、胶囊和根骨。

在 UE 用实际蒙皮顶点验证平地、斜坡和单脚摆动，实机复查台阶、跑停、蹲起和切换外观。幅度明显偏大时先回查尺度、参考姿势和权重。

## UUEPBS 原生验证

1. **识别。** 检查已安装版本的角色收集逻辑、`BoneDictionary` 和原玩家条目实际命中的主网格。用骨名对照目标滑块分组，保留原玩家的其他调节路线。
2. **求值。** 新控制骨可能无顶点权重，并在某些 LOD 被 Required Bones 裁掉。可在控制链末端用独立命名且启用 `bForceAlwaysAnimated` 的 socket 保留求值，按版本检查有效范围。对 Cook 后的主网格输入默认与非默认缩放，从父骨空间回读并检查真实服装变形，以及与腿部和脚底补偿叠加后的结果。
3. **重绑。** 桥接只写自有动画实例的变量，换装、过场与重建后重新定位目标实例。验证关闭 UUEPBS 时的默认外观。开启后在实际 F6 面板检查原玩家条目、目标滑块、原有体型调节、预设重载、过场继承及返场。Lua 模拟和 UE 姿势验证分别记入报告。
